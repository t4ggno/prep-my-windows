Hides the **Home page** in Settings, which shows recommendations, Microsoft 365 and Game Pass promotions. Settings then opens on *System*.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Hidden** | `hide:home` | Settings opens without the Home page. |
| **Shown** | Not set | Windows default. Settings opens on Home. |

> **Good to know:** **Shown** removes the whole page visibility value, so any other Settings pages hidden through the same value become visible again.
