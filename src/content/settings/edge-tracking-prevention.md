Sets how strictly Edge **blocks trackers** from websites.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Off** | `0` | No trackers are blocked. |
| **Basic** | `1` | Blocks only harmful trackers such as cryptominers. |
| **Balanced** | `2` | Edge default. Blocks trackers from sites you have not visited. |
| **Strict** | `3` | Blocks most trackers across all sites. |

> **Good to know:** **Strict** can break some site features, such as embedded videos or logins. Add exceptions in Edge's privacy settings when needed.
