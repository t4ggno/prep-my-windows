Turns off the **ToggleKeys** shortcut — holding **Num Lock for five seconds**.

### Why it matters
- Prevents an unexpected accessibility prompt while you use the number pad.

### Values
| State | Meaning |
| --- | --- |
| **Disabled** | Holding Num Lock does nothing. |
| **Enabled** | Windows default. The shortcut turns on ToggleKeys, which beeps on lock keys. |
| **In use** | ToggleKeys is turned on, so the shortcut is left alone. |
