The **Adobe Update Service** keeps Creative Cloud apps up to date in the background.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |

> **Good to know:** *Manual* keeps updates from the Creative Cloud app working.
