Controls how Edge communicates with Microsoft's **experimentation and configuration service**.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Off** | `0` | Only download configurations needed for security fixes. |
| **Configurations only** | `1` | Download configurations, but no feature experiments. |
| **Configurations and experiments** | `2` | Edge default. Microsoft may test features on your browser. |
