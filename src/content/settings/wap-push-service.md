The **Device Management WAP Push message Routing Service** (`dmwappushservice`) routes device-management and diagnostic push messages.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Windows default. Starts when a message arrives. |
| **Disabled** | `4` | Never starts. |

> **Good to know:** Keep it if this PC is managed through Intune or another MDM service.
