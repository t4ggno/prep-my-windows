Turns off the **Application Telemetry** engine, which tracks how Windows components and apps are used.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Windows default. App usage is tracked. |
| **Off** | `0` | Application telemetry is disabled. |

> **Good to know:** Program Compatibility Assistant warnings for known incompatible apps may be less accurate.
