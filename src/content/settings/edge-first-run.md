Skips Edge's **first-run experience** — the welcome pages, sign-in prompts and data import wizard on first launch.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Edge default. The welcome flow appears on first launch. |
| **Off** | `1` | Edge opens directly without the welcome flow. |

> **Good to know:** Like every Edge policy, this makes Edge show *"Your browser is managed by your organization"* in its settings.
