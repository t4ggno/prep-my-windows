Turns off **Edge sync** of favourites, passwords, history and settings with your Microsoft account.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Edge default. You can sync browser data. |
| **Off** | `1` | Sync is disabled. |

> **Good to know:** Set to **On** if you use Edge on several devices and rely on synced passwords.
