Stops **Google Chrome** from asking to become the default browser.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Chrome asks to become the default browser. |
| **Off** | `0` | Chrome never asks. |

> **Good to know:** Chrome can no longer be made the default browser from its own settings; use Windows Settings instead. Browser policies make the browser show *"managed by your organization"* in its settings.
