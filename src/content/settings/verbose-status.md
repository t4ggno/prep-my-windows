Shows **detailed messages** during startup, shutdown, sign-in and sign-out, such as "Stopping services…".

### Why it matters
- Shows what Windows is waiting for when startup or shutdown takes long.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Detailed status messages are shown. |
| **Off** | `0` | Windows default. Only generic messages are shown. |

> **Good to know:** This rule is optional.
