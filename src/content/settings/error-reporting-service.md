The **Windows Error Reporting Service** (`WerSvc`) collects and uploads crash reports.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Windows default. Starts when an app crashes. |
| **Disabled** | `4` | Never starts; no reports are processed. |
