**Game DVR** is the Xbox Game Bar recorder that can capture gameplay in the background.

### Why it matters
- Background recording keeps the GPU encoder busy and can cost frames or add stutter.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Windows default. Game DVR may record. |
| **Off** | `0` | Game DVR is turned off for this user. |

> **Good to know:** Use your GPU vendor's tools (NVIDIA ShadowPlay, AMD ReLive) if you still want instant replays.
