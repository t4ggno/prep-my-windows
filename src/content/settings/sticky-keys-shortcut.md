Turns off the **StickyKeys** shortcut — pressing **Shift five times** — so it no longer pops up during games or fast typing.

### Why it matters
- The prompt interrupts full-screen games and steals focus.

### Values
| State | Meaning |
| --- | --- |
| **Disabled** | Pressing Shift five times does nothing. |
| **Enabled** | Windows default. The shortcut opens the StickyKeys prompt. |
| **In use** | StickyKeys is turned on, so the shortcut is left alone. |

> **Good to know:** StickyKeys itself stays available in *Settings → Accessibility → Keyboard*.
