Adds **End task** to the right-click menu of apps on the taskbar, so a frozen app can be closed without opening Task Manager.

### Why it matters
- One click kills a hung app and all of its processes.
- It is the same option that Windows hides under *Settings → System → For developers*.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | The taskbar menu shows **End task**. |
| **Off** | `0` | Windows default. The option is not shown. |

> **Good to know:** Requires Windows 11 23H2 (build 22631) or newer. Unsaved work in the closed app is lost.
