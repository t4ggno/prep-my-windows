The page **File Explorer** opens when you start it.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **This PC** | `1` | Opens with your drives and devices. |
| **Home** | `2` | Windows default. Opens Home with recent and pinned items. |
| **Downloads** | `3` | Opens the Downloads folder. |

> **Good to know:** This rule is optional.
