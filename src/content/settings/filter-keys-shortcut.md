Turns off the **FilterKeys** shortcut — holding the **right Shift key for eight seconds**.

### Why it matters
- Holding Shift, for example to sprint in games, can open the FilterKeys prompt or slow down key repeats.

### Values
| State | Meaning |
| --- | --- |
| **Disabled** | Holding right Shift does nothing. |
| **Enabled** | Windows default. The shortcut turns on FilterKeys. |
| **In use** | FilterKeys is turned on, so the shortcut is left alone. |
