The **Lenovo Universal Device Client** (`UDClientService.exe`) runs diagnostics and collects device data for Lenovo Vantage, Legion Space and Lenovo support.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |

> **Good to know:** *Manual* keeps Lenovo apps working because they can still start the service when needed.
