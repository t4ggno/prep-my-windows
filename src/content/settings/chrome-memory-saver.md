Turns on **Memory Saver**, which frees memory from tabs you have not used for a while.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Inactive tabs are discarded to free memory. |
| **Off** | `0` | Chrome default. Tabs stay in memory. |

> **Good to know:** Discarded tabs reload when you return to them. Browser policies make the browser show *"managed by your organization"* in its settings.
