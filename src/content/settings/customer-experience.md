Turns off the legacy **Customer Experience Improvement Program** (CEIP), which collects usage statistics.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | CEIP data is collected. |
| **Off** | `0` | CEIP is turned off. |

> **Good to know:** Pair it with the **CEIP Consolidator**, **USB CEIP** and **Kernel CEIP** scheduled tasks below.
