Shows or hides the **Widgets** button (weather and news) on the taskbar for the current user.

### Why it matters
- Hovering the button opens the news feed by accident and loads web content.

### Values
| Option | Meaning |
| --- | --- |
| **Hidden** | The button is removed from the taskbar. |
| **Visible** | Windows default. The button is shown. |

> **Good to know:** Windows protects this value with **User Choice Protection**. The rule only works after that driver is off and Windows was restarted.
