Stops downloads of **disk health models**, which Windows uses to predict failing drives.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Windows default. Updated models are downloaded. |
| **Off** | `0` | No model downloads. |

> **Good to know:** Windows still shows drive health in *Settings → Storage → Disks & volumes* with the existing model.
