Turns off the **Firefox Default Browser Agent**, a scheduled task that runs daily in the background.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | The agent reports default browser settings to Mozilla. |
| **Off** | `1` | The agent does not run. |

> **Good to know:** Browser policies make the browser show *"managed by your organization"* in its settings.
