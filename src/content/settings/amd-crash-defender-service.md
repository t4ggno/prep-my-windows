**AMD Crash Defender** (`amdfendrsr.exe`) collects driver crash data and runs permanently in the background.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |

> **Good to know:** Windows still recovers from driver timeouts; AMD only receives fewer crash reports.
