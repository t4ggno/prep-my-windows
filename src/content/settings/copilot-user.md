Turns **Windows Copilot** off for the current user through policy.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Windows default. Copilot may be used. |
| **Off** | `1` | Copilot is turned off for this user. |

> **Good to know:** Newer Windows versions ship Copilot as a regular app; remove it on the **Apps** page as well.
