Shows the technical stop code parameters on the blue crash screen instead of only a sad face and a QR code.

### Why it matters
- The extra parameters identify the failing driver or component.
- Useful when you search for the cause of a crash or report it to a vendor.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | The crash screen lists the stop code parameters. |
| **Off** | `0` | Windows default. Only the simplified crash screen is shown. |
