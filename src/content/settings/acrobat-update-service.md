The **Adobe Acrobat Update Service** (`AdobeARMservice`) runs permanently so Acrobat can install updates.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |

> **Good to know:** *Manual* keeps updates working because the Acrobat updater starts the service when it needs it.
