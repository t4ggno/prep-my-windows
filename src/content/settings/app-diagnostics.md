Controls whether apps can read **diagnostic information about other apps**.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **User decides** | `0` | Windows default. You control access in Settings. |
| **Force allow** | `1` | All apps get access; the switch in Settings is locked. |
| **Deny** | `2` | No app gets access; the switch in Settings is locked. |
