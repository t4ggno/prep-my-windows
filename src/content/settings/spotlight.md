Turns off all **Windows Spotlight** features for the current user: lock screen images, suggestions and tips.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Windows default. Spotlight features are available. |
| **Off** | `1` | All Spotlight features are turned off. |

> **Good to know:** You can still pick your own lock screen picture or slideshow.
