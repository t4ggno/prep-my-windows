Controls how much **telemetry** Visual Studio Code and its extensions send.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Off** | `off` | No telemetry is sent. |
| **Crash reports** | `crash` | Only crash reports. |
| **Errors** | `error` | Crash reports and errors. |
| **All** | `all` | VS Code default. Usage data, errors and crash reports. |
