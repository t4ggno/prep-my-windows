Controls **"Get the latest updates as soon as they're available"** in Windows Update.

### Why it matters
- With it on, Windows enables new and still-rolling-out features early, including new Copilot and AI features.
- Off keeps you on the regular, more tested rollout. Security updates are not affected.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | New features are switched on as soon as possible. |
| **Off** | `0` | Windows default. Features arrive in the normal rollout. |
