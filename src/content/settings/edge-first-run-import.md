Controls **automatic data import** from other browsers when Edge starts for the first time.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Off** | `4` | Nothing is imported automatically. |
| **From default browser** | `0` | Data and settings of your default browser are imported. |
| **From Google Chrome** | `2` | Data and settings of Chrome are imported. |

> **Good to know:** You can still import manually in *Edge settings → Profiles → Import browser data*.
