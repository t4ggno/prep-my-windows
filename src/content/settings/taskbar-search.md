How **search** appears on the Windows 11 taskbar.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Hidden** | `0` | No search on the taskbar; use **Win** or **Win + S**. |
| **Icon** | `1` | A compact search icon. |
| **Search box** | `2` | Windows default. A wide search box, often with search highlights. |
| **Icon and label** | `3` | A search icon with the word "Search". |
