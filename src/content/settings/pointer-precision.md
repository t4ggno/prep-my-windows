**Enhance pointer precision** is Windows' mouse acceleration: the pointer moves farther when you move the mouse faster.

### Why it matters
- Without acceleration, the same hand movement always moves the pointer the same distance — essential for consistent aim in games.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Windows default. Mouse acceleration is active. |
| **Off** | `0` | Pointer movement is 1:1 with the mouse. |

> **Good to know:** Takes effect after signing out and back in.
