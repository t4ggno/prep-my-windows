Clicking an app with several windows on the taskbar opens its **last active window** instead of showing thumbnails.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | One click returns to the window you used last. |
| **Off** | `0` | Windows default. A click shows thumbnails of all windows. |

> **Good to know:** This rule is optional.
