When on, Windows makes the **printer you used last** the default printer at your current location.

### Why it matters
- Off keeps the default printer you chose, no matter which printer you used last.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Windows default. Windows switches the default printer automatically. |
| **Off** | `1` | Your chosen default printer stays the default. |
