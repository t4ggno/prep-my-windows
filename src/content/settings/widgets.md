Allows or blocks the **Widgets** board with news, weather and MSN content, enforced as a policy.

### Why it matters
- Widgets load web content in the background and promote news feeds.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Widgets are allowed. |
| **Off** | `0` | Widgets are blocked for all users. |

> **Good to know:** Windows protects this value with **User Choice Protection**. The rule only works after that driver is off and Windows was restarted.
