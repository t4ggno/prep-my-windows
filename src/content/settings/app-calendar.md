Controls whether apps can read your **calendar**.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **User decides** | `0` | Windows default. You control access in Settings. |
| **Force allow** | `1` | All apps get access. |
| **Deny** | `2` | No app gets access. |

> **Good to know:** The calendar in the taskbar clock flyout no longer shows events when set to **Deny**.
