Shows or hides **hidden files and folders**, such as `AppData` or `.git`.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Shown** | `1` | Hidden items appear, slightly faded. |
| **Hidden** | `2` | Windows default. Hidden items are not shown. |

> **Good to know:** This rule is optional. Protected system files stay hidden either way.
