**Startup boost** starts Edge processes in the background when you sign in, so Edge opens faster.

### Why it matters
- Edge uses memory and CPU at every sign-in, even if you use another browser.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Edge default. Edge is preloaded at sign-in. |
| **Off** | `0` | Edge only starts when you open it. |
