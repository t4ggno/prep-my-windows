Opens **Xbox Game Bar** when you press the Xbox button on a controller.

### Why it matters
- Steam, launchers and handheld tools often use the Xbox button themselves; Game Bar then pops up over your game.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Windows default. The Xbox button opens Game Bar. |
| **Off** | `0` | The Xbox button no longer opens Game Bar. |
