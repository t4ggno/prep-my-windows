Allows or blocks **web search** from Windows Search, enforced as a policy.

### Why it matters
- Prevents search terms from being sent to Bing and keeps web results out of local search.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Windows default. Web search is allowed. |
| **Off** | `1` | Web search is blocked. |
