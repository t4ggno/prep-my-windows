Controls whether apps can use the **camera**.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **User decides** | `0` | Windows default. You control access in Settings. |
| **Force allow** | `1` | All apps get access. |
| **Deny** | `2` | No app gets access. |

> **Good to know:** This rule is optional. **Deny** breaks video calls and Windows Hello face sign-in for apps that use the camera.
