Turns off **user tracking** in File Explorer and Start, which records which programs and shell features you use.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Off** | `1` | Shell usage is not recorded. |
| **On** | `0` | Windows default. Usage is recorded. |

> **Good to know:** Start may show fewer "most used" apps because Windows no longer learns your habits.
