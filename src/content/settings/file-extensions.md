Shows or hides the extension at the end of file names in File Explorer, such as `.pdf`, `.exe` or `.jpg`.

### Why it matters
- With hidden extensions, a malicious `invoice.pdf.exe` looks like the harmless `invoice.pdf`.
- Seeing the real type makes renaming and troubleshooting files much easier.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Shown** | `0` | Every file shows its extension. |
| **Hidden** | `1` | Windows default. Extensions of known file types are hidden. |
