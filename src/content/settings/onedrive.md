Allows or blocks **OneDrive file sync** for the whole PC.

### Why it matters
- Stops OneDrive from starting, syncing and nagging you to back up your folders.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Windows default. OneDrive can sync files. |
| **Off** | `1` | OneDrive cannot sync or be used. |

> **Good to know:** If you store files in OneDrive, set this to **On** — otherwise your files stop syncing and only the cloud copy stays up to date.
