The **Adobe Genuine Monitor Service** (`AGMService`) is an older version of Adobe's genuine software check that runs in the background.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |
