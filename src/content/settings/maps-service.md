The **Downloaded Maps Manager** (`MapsBroker`) keeps offline maps for the Windows Maps app up to date.

### Why it matters
- The Maps app is retired; the service mostly checks for map updates in the background.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |
