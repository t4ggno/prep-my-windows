**Game Mode** prioritises the game you are playing: Windows Update pauses driver installs and restarts, and background work gets fewer resources.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | Windows default. Game Mode is active while games run. |
| **Off** | `0` | Games run without Game Mode. |

> **Good to know:** On modern systems Game Mode rarely hurts; turn it off only if a specific game stutters with it.
