Restores the **full right-click menu** in File Explorer, like in Windows 10, instead of the compact menu with *Show more options*.

### Why it matters
- All commands, including those of third-party apps like 7-Zip or Git, are available with one right-click.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | Empty | The full context menu is always shown. |
| **Not set** | — | Windows default. The compact Windows 11 menu is shown. |

> **Good to know:** Takes effect after File Explorer restarts or you sign in again. To get the compact menu back, turn this rule off, delete the registry key below and restart File Explorer.
