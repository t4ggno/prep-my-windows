The **Retail Demo** service (`RetailDemo`) controls the demo mode that shops use on display PCs.

### Why it matters
- It has no use on a personal PC.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Windows default. Starts only when retail demo mode needs it. |
| **Disabled** | `4` | Never starts. |
