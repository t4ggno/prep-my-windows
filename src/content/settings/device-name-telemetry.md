Decides whether the **device name** is included in diagnostic data.

### Why it matters
- Device names often contain personal names ("ANNAS-LAPTOP"), linking diagnostic data to a person.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `1` | The device name is sent with diagnostic data. |
| **Off** | `0` | The device name is not sent. |
