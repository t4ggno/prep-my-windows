The **Distributed Link Tracking Client** (`TrkWks`) keeps shortcuts working when linked files move between NTFS drives or computers in a network.

### Why it matters
- Designed for corporate domains; on home PCs it mainly runs in the background.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Windows default. Starts with Windows. |
| **Manual** | `3` | Starts when requested. |
| **Disabled** | `4` | Never starts. |
