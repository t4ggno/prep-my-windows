The **Adobe Genuine Software Integrity Service** (`AGSService`) scans for non-genuine Adobe software and shows warnings.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts only when an app needs it. |
| **Disabled** | `4` | Never starts. |

> **Good to know:** Licensed Creative Cloud apps keep working without it.
