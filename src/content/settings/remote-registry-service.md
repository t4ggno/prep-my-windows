The **Remote Registry** service (`RemoteRegistry`) lets other computers on the network read and change this PC's registry.

### Why it matters
- A classic attack surface that home PCs never need.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Automatic** | `2` | Starts with Windows. |
| **Manual** | `3` | Starts when something requests it. |
| **Disabled** | `4` | Never starts. |
