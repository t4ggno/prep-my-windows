Controls **web suggestions** in the Start and taskbar search box.

### Why it matters
- Every keystroke in Windows Search can be sent to Bing to fetch suggestions.
- Without them, search stays fast and local: apps, files and settings.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **On** | `0` | Windows default. Search shows web suggestions. |
| **Off** | `1` | Web suggestions are removed from search. |
