Removes the **Logitech Download Assistant**, which checks for Logitech software and shows install prompts, from the programs that start when you sign in.

### Values
| Option | Value | Meaning |
| --- | --- | --- |
| **Off** | Not set | The assistant no longer runs at sign-in. |

> **Good to know:** Turning on the program's own start-at-sign-in option is undone at the next check. The program still opens normally when you start it.
